Hunter's Game uses these existing tools and resources:

  • Phaser 3 — game engine, interaction, animation, and Matter physics. MIT license.
  • d3-delaunay — Voronoi glass fragments. ISC license.
  • Unicorn and rainbow emojis designed by OpenMoji — the open-source emoji and icon project. Licensed under CC BY-SA 4.0. The bundled SVG artwork is unmodified; the game animates it. Full license.
  • Runtime library license notices.

The game generates its block letters, cracks, particles, and sounds locally. No account or external asset service is required to play.
